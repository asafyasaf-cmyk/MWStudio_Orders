# MW Studio – מערכת הזמנות חיתוך וכיפוף

מערכת הזמנה אונליין לחלקי פח בחיתוך לייזר וכיפוף, עם תצוגת תלת־ממד, מחשבון מחיר ושליחת הזמנה בוואטסאפ.

## מה יש היום
- **תבניות מוכנות**: פלטה, עיגון, עיגול/פלאנג׳, טבעת, זווית L, תעלת U, פרופיל Z, מגש/קופסה.
- **העלאת DXF**: ניתוח קווי חיתוך, חורים ופריצות, ושכבת `BEND` לקווי כיפוף.
- **תצוגת 3D** (three.js): מידות, אנימציית כיפוף, השוואת גודל לדף A4 / אדם.
- **בדיקות ייצור**: כנף קצרה מדי, חור קרוב לכיפוף, חורים חופפים, חריגה מגיליון 3000×1500.
- **מחשבון מחיר**: חיתוך, פריצות, משקל חומר, כיפופים וצבע RAL.
- **עוזר צ׳אט**: בתוך Claude Artifact הוא משתמש ב־Claude; מחוץ לו עובר לפענוח טקסט פשוט מקומי.
- **הזמנה**: בדיקת שם וטלפון, ואז כפתור ששולח את ההזמנה ישירות בוואטסאפ (או העתקת הטקסט).

## הרצה מקומית
זה קובץ HTML אחד, בלי שלב build:

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

## מספר הוואטסאפ של העסק
בתוך `index.html`:

```js
const SHOP_WHATSAPP='972501234567'; // בלי + ובלי 0 בהתחלה
```

אם נשאר ריק, הלקוח בוחר בעצמו למי לשלוח.

## הגדרות מחיר
בתוך `index.html`, באובייקט `PRICE`:

```js
const PRICE={cutPerMm:0.02,perPierce:3,perKg:{steel:9,galv:12,ss:30,al:32},perBend:6,paintPerM2:70};
```
