# MW Studio – מערכת הזמנות חיתוך וכיפוף

מערכת הזמנה אונליין לחלקי פח בחיתוך לייזר וכיפוף, עם תצוגת תלת־ממד, מחשבון מחיר ושליחת הזמנה בוואטסאפ.

## מה יש היום
- **תבניות מוכנות**: פלטה, עיגון, עיגול/פלאנג׳, טבעת, זווית L, תעלת U, פרופיל Z, מגש/קופסה.
- **קטלוג פרופילים**: צינור מרובע/מלבני/עגול, זוויתן, פס שטוח, מוט עגול, UPN, IPE, HEA, HEB, עם מידות ומשקלים לפי התקנים האירופיים (EN 10219, EN 10056, EN 10058, EN 10060, EN 10365, DIN 1026). חיתוך לאורך, ציור חתך, חישוב מוטות 6/12 מ׳, מחיר.
- **חורים וחירוצים בפרופיל**: לחיצה על הפרופיל בתלת־ממד או הוספה מהרשימה; חור (צד, מיקום, היסט, קוטר, שורת חורים, עובר/דופן אחת), חירוץ ישר או V לכיפוף. החיתוך אמיתי במודל (CSG), עם אזהרות, מחיר לקידוח/חירוץ ופירוט בהזמנה.
- **העלאת DXF**: ניתוח קווי חיתוך, חורים ופריצות, ושכבת `BEND` לקווי כיפוף.
- **תצוגת 3D** (three.js): מידות, אנימציית כיפוף, השוואת גודל לדף A4 / אדם.
- **בדיקות ייצור**: כנף קצרה מדי, חור קרוב לכיפוף, חורים חופפים, חריגה מגיליון 3000×1500.
- **מחשבון מחיר**: חיתוך, פריצות, משקל חומר, כיפופים וצבע RAL.
- **עוזר צ׳אט וקריאת שרטוטים**: הלקוח כותב, מצלם שרטוט בעט או מצייר, והמערכת בונה את החלק (כולל חורים וחירוצים בפרופיל). באתר הציבורי זה עובר דרך סקריפט Google Sheets עם מפתח Anthropic שלכם (ראו `google-sheets/README.md`); בלי מפתח, פענוח טקסט פשוט.
- **הזמנה**: בדיקת שם וטלפון, מספר הזמנה (MW-שנה חודש יום-XXXX), שמירה ב-Google Sheets עם סטטוס, ושליחה ישירה בוואטסאפ.

## הרצה מקומית
זה קובץ HTML אחד, בלי שלב build:

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

## מספר הוואטסאפ של העסק
בתוך `index.html`:

```js
const SHOP_WHATSAPP='972501234567'; // בלי + ובלי 0 בהתחלה
```

אם נשאר ריק, הלקוח בוחר בעצמו למי לשלוח.

## שמירת הזמנות
ההזמנות נשמרות בגיליון Google Sheets שלכם. הוראות התקנה: [`google-sheets/README.md`](google-sheets/README.md).
אחרי ההתקנה מדביקים את הכתובת ב-`index.html`:

```js
const ORDERS_ENDPOINT='https://script.google.com/macros/s/.../exec';
```

## הגדרות מחיר
בתוך `index.html`, באובייקט `PRICE`:

```js
const PRICE={cutPerMm:0.02,perPierce:3,perKg:{steel:9,galv:12,ss:30,al:32},perBend:6,paintPerM2:70};
```

## חיבור הקטלוג למקור חיצוני
הקטלוג נטען דרך `CatalogSource.load()` ב-`index.html`. היום הוא מחזיר טבלאות מובנות.
כדי לסנכרן מול ספק או API (למשל steelyard), מחליפים את `load()` ב-fetch שמחזיר את אותו מבנה:

```js
[{id:'shs', name:'צינור מרובע', std:'EN 10219', mats:['steel','galv'], stock:[6000], def:'40x40x3',
  dims:[['B','צלע'],['t','דופן']], sizes:[{id:'40x40x3', label:'40×40×3', d:{B:40,H:40,t:3}, kgm:3.30}]}]
```

מחירי פרופילים: `PRICE.prof` (מחיר לק״ג לפי חומר, חיתוך, עובי מסור, `perHole` לקידוח, `perNotch` לחירוץ).
