# שמירת הזמנות ב-Google Sheets

כל הזמנה מהאתר נוספת כשורה בגיליון, עם מספר הזמנה ועמודת סטטוס לבחירה:
**התקבלה · בטיפול · בייצור · מוכנה · נמסרה · בוטלה** (כל סטטוס בצבע אחר).

## התקנה (פעם אחת, כ-5 דקות)
1. פותחים גיליון חדש: https://sheets.new ונותנים לו שם, למשל "הזמנות MW Studio".
2. בתפריט: **הרחבות (Extensions) ← Apps Script**.
3. מוחקים את מה שכתוב שם ומדביקים את כל התוכן של [`Code.gs`](Code.gs). שומרים (Ctrl+S).
4. למעלה בוחרים את הפונקציה **setup** ולוחצים **▶ Run**. Google יבקש אישור הרשאות לגיליון: **Review permissions** ← בוחרים את החשבון ← **Advanced** ← **Go to … (unsafe)** ← **Allow**.
   (זו האזהרה הרגילה לסקריפט פרטי שלא עבר אימות של Google. הסקריפט כותב רק לגיליון הזה.)
5. **Deploy ← New deployment** ← בגלגל השיניים בוחרים **Web app**:
   - **Execute as:** Me
   - **Who has access:** Anyone
   - **Deploy**
6. מעתיקים את ה-**Web app URL** (מתחיל ב-`https://script.google.com/macros/s/`) ושולחים לי, או מדביקים בעצמכם ב-`index.html`:
   ```js
   const ORDERS_ENDPOINT='https://script.google.com/macros/s/.../exec';
   ```

## קובצי STEP
בהזמנת פרופיל נוצר קובץ STEP (הפרופיל עם החורים והחירוצים) ונשמר ב-Google Drive שלכם בתיקייה **"MW Studio – קובצי STEP"**. הקישור מופיע בעמודה **"קובץ STEP"** בשורת ההזמנה. בפעם הראשונה Google יבקש אישור גישה ל-Drive (מריצים שוב את setup).

## התראה במייל (לא חובה)
ב-`Code.gs` ממלאים `const NOTIFY_EMAIL='you@example.com';`, שומרים, ואז **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy** (הכתובת נשארת אותה כתובת).

## חשוב לדעת
- כל שינוי בסקריפט נכנס לתוקף רק אחרי **New version** ב-Manage deployments.
- הכתובת מקבלת הזמנות מכל אחד (כמו כל טופס באתר). יש מלכודת בוטים פשוטה, והסקריפט מונע נוסחאות זדוניות בתאים.
- אם השמירה נכשלת, הלקוח רואה הודעה ועדיין יכול לשלוח בוואטסאפ.

## קריאת שרטוטים ותמונות עם AI (לא חובה)
אחרי ההגדרה, באתר הציבורי מופיעים כפתורי **📷 תמונה** ו-**✏️ ציור**. הלקוח מצלם שרטוט בעט (או מצייר באצבע), והמערכת בונה את הפרופיל או החלק עם החורים והחירוצים, ומציגה בתלת־ממד לבדיקה לפני הזמנה. אפשר גם לכתוב בצ׳אט בחופשיות.

הבקשה עוברת דרך הסקריפט שלכם ל-Claude, כך שמפתח ה-API לעולם לא נמצא באתר.

1. פותחים חשבון ב-https://console.anthropic.com, מוסיפים אמצעי תשלום, ויוצרים **API key**.
   מומלץ להגדיר שם **תקרת הוצאה חודשית** (Limits).
2. ב-Apps Script: **⚙️ Project Settings ← Script properties ← Add script property**:
   - Property: `ANTHROPIC_API_KEY`
   - Value: המפתח (מתחיל ב-`sk-ant-`)
3. מריצים שוב את **setup** (▶ Run) ומאשרים את ההרשאה החדשה ("Connect to an external service").
4. **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy**.

### עלות ומגבלות
- כל קריאת שרטוט היא בקשה אחת למודל Claude Opus 5.5 (ראו מחירון ב-https://claude.com/pricing). התשלום הוא לחשבון Anthropic שלכם.
- `AI_DAILY_LIMIT` ב-`Code.gs` (ברירת מחדל 150 בקשות ליום) מגביל שימוש לרעה. אחרי המגבלה הלקוח מקבל "יש עומס רגעי".
- בלי מפתח, האתר עובד כרגיל עם פענוח טקסט פשוט, וכפתורי התמונה מוסתרים.
- AI יכול לטעות בקריאת שרטוט ידני. הלקוח רואה את התוצאה בתלת־ממד ובמידות ויכול לתקן לפני הזמנה.
